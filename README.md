# Viber 大陆 · 风栖之旅

一个可直接游玩的轻量多人冒险世界：采集、制作、战斗、钓鱼、探索、伙伴陪伴、种花、换装、委托与建房。Three.js / WebGL 立体画面 + Node.js + WebSocket，无前端构建步骤；无法初始化 WebGL 时自动使用 Canvas 兼容画面。

## 启动

需要 Node.js 20 或更新版本。首次克隆仓库后，按锁定版本安装依赖：

```bash
npm ci
npm start
# http://localhost:8790
```

如果 8790 被其他项目使用，指定 `PORT=8792 npm start`。服务默认只监听本机；需要局域网联机时，可显式设置 `HOST=0.0.0.0`，其他玩家通过这台电脑的局域网 IP 访问同一端口。

防刷限制（按客户端 IP）：同时最多 8 个连接（`MAX_CONN_PER_IP`）、每分钟最多 30 次新连接（`CONN_PER_MINUTE`）、每分钟最多 12 次购买报价（`BUY_QUOTES_PER_MINUTE`）。游客只有真正操作过才会写入存档，闲置超过 30 天（`GUEST_TTL_DAYS`）或总数超过 5000（`MAX_GUESTS`）时清理最旧的。**通过 Cloudflare 隧道或反向代理公开时**，所有玩家看起来都来自同一个本机 IP，必须同时设置 `TRUST_PROXY=1`（按 `CF-Connecting-IP` / `X-Forwarded-For` 区分玩家）；直接对外开放端口时不要设置它，否则 IP 可被伪造。

```bash
npm run start:offline   # 纯冒险模式，不发出链上请求
npm test               # 游戏规则 + 独立服务器联机测试
```

链上 RPC 暂时失败不会阻止游戏启动。当前配置使用原项目的 Robinhood **测试网（46630）**；不能直接替换为不同 chain ID 的共享主网网关。服务端 `RPC_URL` 可以覆盖读链地址，但不会把该私有地址透传给浏览器钱包。

## GitHub 与本地同步

仓库地址：[Nuantree/Vibers](https://github.com/Nuantree/Vibers)，日常开发分支为 `main`。

本地项目通过 Git 的 `origin` 连接 GitHub。保存文件后，需要提交并推送，GitHub 才会更新；从 GitHub 获取修改需要拉取。不会在后台自动上传。

开始修改前，在项目目录运行：

```bash
git status --short --branch
git pull --ff-only
```

如果状态显示未提交的修改，先提交或妥善保存本地工作再拉取。完成修改后：

```bash
npm test
git status --short
git diff
git add .
git diff --cached --stat
git commit -m "描述这次修改"
git push
```

`git add .` 会包含所有未被忽略的修改，提交前确认文件列表。只想上传部分文件时，改为 `git add 文件名`。如果提示没有需要提交的改动，跳过 `commit`；已有本地提交仍可执行 `git push`。

如果远程在你修改期间也有新提交，推送会被拒绝。先确保本地修改已提交，再运行 `git pull --rebase`，解决冲突后执行 `git rebase --continue`，最后 `git push`；需要退出这次变基可执行 `git rebase --abort`。不要用强制推送覆盖远程修改。

换电脑时：

```bash
git clone https://github.com/Nuantree/Vibers.git
cd Vibers
npm ci
npm start
```

上传修改需要登录具有仓库写入权限的 GitHub 账号；命令行可使用 `gh auth login` 登录，并执行 `gh auth setup-git` 配置 Git 认证。

同步包含源码、测试、依赖锁文件和随项目提供的 Three.js 模块；不包含 `node_modules/`、`data.json` 玩家存档、`.env*` 私密配置、日志及本地编辑器设置。自定义 `DATA_FILE` 时，请把存档放在仓库外，或为该路径添加忽略规则。游戏进度需单独备份。

配置目前通过环境变量传入，项目不会自动读取 `.env` 文件。例如设置自己的测试网代币地址：

```bash
TOKEN_ADDRESS=0x你的代币地址 LORD_MIN=100000 npm start
```

## 从这里开始

1. 填名字、选择披风颜色，直接进入小镇，无需连接钱包。
2. 点击左侧「追踪目标」，自动走到树木旁采集；资源耗尽后可以追踪下一处。
3. 完成委托后点击「领取奖励」，赚取金币和经验。
4. 先点击右侧「去练习木桩」，练习三段连击、翻滚和回旋斩；再采矿采药，在林间工坊制作长剑、护甲、钓竿或药水。
5. 去森林挑战史莱姆，到镜月湖钓鱼，到守望者遗迹挑战守卫并寻找宝箱。
6. 生命不足时喝药或回小镇篝火休息。倒下会被带回小镇，金币和背包不丢失。

## 小镇生活 · v0.4

- **同行伙伴**：到篝火旁免费结识绒尾小狐或奶油小兔，自动跟随、蹦跳、眨眼和摇尾巴。可以起名，切换伙伴会保留名字与亲密度。每 15 秒摸摸一次增加 1 亲密；赠送月光草 / 银鳞鱼 / 星铃花分别增加 2 / 4 / 8，上限 100。亲密 20 解锁金色领饰，60 解锁耳畔小花。伙伴不会受伤，也不参与战斗。
- **个人花圃**：篝火北边有三块花圃，初始 3 颗种子。月光草 60 秒成熟、产出 2 份；星铃花 90 秒成熟、产出 1 份。浇水一次让剩余时间减半；收获返还 1 颗种子并增加 8 经验。离线也会生长，不会枯萎。每位旅人的花圃独立保存，成熟时顶部爪印显示提醒。
- **旅人衣橱**：苔绿、琥珀、鸢尾、莓果、雾蓝五种披风免费更换，联机旅人也能看见。可以挥手、比心或坐下休息，移动和战斗会结束动作。
- **细节演出**：人物会眨眼、轻轻转头，村庄有蝴蝶，花苗随时间长大，摸摸和收获带有粒子及合成音效；减少动态效果设置会关闭蝴蝶等装饰演出。
- 伙伴、名字、亲密度、种植时间、种子和披风都进入原有存档。距离、冷却、礼物消耗和收获奖励由服务端校验，重复请求不能多领。

## 内容与成长

- **5 个地标**：风栖小镇、低语森林、暮石矿场、镜月湖、守望者遗迹。
- **7 项委托**：采木、采矿、制作、清怪、钓鱼、探索、寻宝；一次领取，按累计行为计数。
- **6 个配方**：精工斧镐、守林人长剑、星辉护甲、柳木钓竿、生命药水、篝火烤鱼。护甲消耗 8 铁矿 + 3 星辉碎片，减伤 25%，装备会改变人物外观。
- **战斗**：7 只苔藓史莱姆、1 个遗迹守卫和镇内练习木桩。敌人攻击前显示红圈，实际命中采用相同圆形范围；守卫半血狂暴。连击、13% 暴击、闪避无敌、体力恢复、技能冷却、击退、掉落和重生均由服务端处理。木桩不奖励经验、金币或击杀次数。
- **4 个个人宝箱**：每个角色每箱只领取一次。其他旅人不会抢走你的宝藏。
- **等级与技能**：经验提升等级和生命上限；采集、钓鱼提升熟练度；斧镐增加采集产量。
- **商店经济**：出售资源获得游戏金币，再兑换药水、草药和铁矿。游戏金币不是链上资产。
- **画面与手感**：立体关节角色、随朝向挥动的武器、披风和护甲，柔和投影、接触阴影、昼夜灯光、水面、篝火、粒子。命中闪白、短暂受击停顿、镜头震动、伤害飘字、三段连击提示、Boss 血条；Web Audio 合成挥剑、命中、技能等音效。首次启程后音效默认开启，可随时关闭。
- **性能与兼容**：植被与矿石使用批量实例渲染；精致 / 流畅两档画质，可减少动态效果、关闭震屏与飘字。手机支持方向键、闪避和技能按钮。Three.js 模块固定在本地 `public/vendor/`，版本 0.186.1，许可证随附，无 CDN 依赖。

## 存档与联机

- `data.json` 保存游客及钱包的背包、技能、装备、等级、任务、探索、宝箱、伙伴、花圃、种子、披风和房屋。旧版钱包存档会补齐新增字段。
- 游客的随机存档凭据留在当前浏览器；同一地址和端口下刷新或重连可以恢复。清除站点数据、换浏览器或换端口不会自动带走游客入口。
- 签名连接新钱包会迁移当前进度；钱包已有存档时，以已有钱包存档为准。钱包断线后需再次签名恢复链上身份。
- 同一存档同时打开两个页面时，后进入的页面接管；前一页面停止自动重连，避免互相踢出。
- 存档每 20 秒落盘，断线与正常退出也会保存；写入使用串行临时文件与原子替换。
- 重新进入时从小镇出生。地图资源和怪物在服务重启后重置；个人任务和宝箱记录保留。

## WIND 代币与钱包身份

默认接入自己的 [WIND 测试网代币](https://testnet.vibevibe.fun/token/0xF08b54449B2f6EDd2D4af0A69DFd0cBfff6C8acB)，合约 `0xF08b54449B2f6EDd2D4af0A69DFd0cBfff6C8acB`。点击右上角钱包可查看代币卡片、复制合约、添加到钱包或进入商店购买。

登录只请求签名，服务端读取 WIND 的 `balanceOf`。持有量达到 `LORD_MIN`（默认 100000 WIND）成为领主，可建房，技能成长 +50%。每 60 秒重读余额；房主持仓不足时房屋荒废，持续 5 分钟后倒塌。游戏金币与 WIND 分别计算。

```bash
TOKEN_ADDRESS=0x你的代币 LORD_MIN=100000 npm start
```

商店支持 WIND 当前发行工厂的 `quoteBuy` / `buy`，并保留旧 V6 兼容路径；仅支持测试网 ETH 曲线阶段购买。提供 0.001 / 0.005 / 0.01 测试 ETH 三档，报价显示预计及最低获得量。交易由玩家自己的钱包确认；提交后明确显示等待链上确认。读取失败显示未知/暂不可用，不冒充零持仓。离线模式禁用所有钱包请求。合约来源、限制与验证记录见 [WIND 接入说明](docs/wind-token.md)。
